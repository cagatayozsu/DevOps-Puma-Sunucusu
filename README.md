# DevOps Projesi: Puma Web Sunucusu Kurulumu
Bu proje, Ubuntu ortamında Ruby tabanlı eşzamanlı (concurrent) Puma web uygulama sunucusunun kurulumu ve yapılandırılmasını içermektedir.

**Odak Noktaları:**
- Hibrit (Fork + Thread) mimarinin incelenmesi.
- Systemd ile servis yönetimi yapılandırması.
- Nginx ile Reverse Proxy ayarları (Nginx + Puma entegrasyonu).
